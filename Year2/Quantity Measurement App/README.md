# Hotel Booking System

A comprehensive hotel booking system demonstrating various Java data structures and design patterns.

## Use Cases

1. **UC1 - Room Management**: Basic room CRUD operations
2. **UC2 - Guest Management**: Guest registration and lookup
3. **UC3 - Basic Booking System**: Simple booking operations
4. **UC4 - Booking Request Queue**: FIFO queue for booking requests
5. **UC5 - Process Booking Queue**: Queue processing logic
6. **UC6 - Inventory HashMap**: HashMap-based room inventory
7. **UC7 - Booking with HashMap**: HashMap-based booking storage
8. **UC8 - Double Booking Prevention**: Prevent duplicate bookings
9. **UC9 - Guest Checkin Tracking**: Track guest check-ins/outs
10. **UC10 - Sorted Booking TreeMap**: TreeMap for sorted bookings
11. **UC11 - Room Availability TreeMap**: TreeMap for inventory
12. **UC12 - Hotel Analytics**: Statistics and reporting
13. **UC13 - Complete Hotel System**: Integrated system with all features
